# Square-grid experiment review

Generated deterministically with `npm run art:square-grid-review`. The desktop DPR1 and mobile DPR2 sheets use the real ruleset-6 draw list with 128 x 128 square projection, native square overlays and temporary accepted diamond-era terrain/improvement rasters. Each native image has a nearest-neighbor 2x inspection copy. No production raster or accepted-art record is created or changed by this review.
