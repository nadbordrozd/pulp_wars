# Ruleset-6 Canvas renderer review

Generated deterministically with `npm run art:ruleset6-renderer-review`. The eight sheets cover Original and Candy at 0.625x, 1x, and 1.75x for DPR1 and DPR2, each at native backing resolution and nearest-neighbor 2x inspection scale.

A yellow `P` is the renderer's explicit non-production marker. It appears only where the coverage contract says production art is missing. Road lines are a deterministic temporary connectivity mask and carry `P` until the required PixelLab material input is accepted. Technology-hidden resources intentionally add no world marker: explored ordinary terrain is the complete visual. Accepted, semantically identical existing rasters are embedded from checked-in files; fog, ownership, targets, economic contributors and statuses remain intentionally code-native.
