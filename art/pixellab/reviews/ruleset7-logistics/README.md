# Ruleset 7 revision-11 logistics art review

Run the checked review with:

```sh
npm run art:ruleset7-logistics-review
```

For an isolated validation run, pass an output directory:

```sh
npm run art:ruleset7-logistics-review -- --output /tmp/pulp-wars-logistics-review
```

The review verifies the exact two-source inventory, accepted hashes and every
submission receipt, geometry, the revision-10/revision-11 Port area comparison,
the open docking window, six disconnected Fish silhouettes, and 258 retained
plus two new production PNGs. The sheets cover transparent source and enlarged
views, native/minimum/maximum zoom at DPR 1 and 2, both water values, grayscale
and adjacent resources, owner/state overlays, all eight coast adjacencies,
one through five Ports, dense coast repetition, Shipyard comparison, and the
production water → building → resource → unit → status draw order.
